# 현재 결과와 남은 검수

입력 준비·평가 코드 검증 완료, 실제 모델 어댑터 및 로컬 실행 통합 중입니다.
최종 실측 표는 실행 후 이 파일에 갱신합니다. 이전 벤치마크의 결과를 새 문제 실행 결과로 재사용하지 않습니다.

확인한 자료: 두 폴더 README, 공통 프롬프트/스키마/샘플링 코드, 6개 실제 MP4 메타데이터·해시,
선택 영상 프레임. 데이터/어노테이션 파일은 포함되어 있지 않습니다. 후보 README의
`benchmark_v1/private_ground_truth/` 참조 경로도 이 작업 폴더에는 없습니다.
README 설명만으로 정답 박스나 확정 사건·호출 여부를 만들 수 없습니다.

문제 구성은 DESIGN.md에서 실행 전에 12개로 고정했습니다. 기존 공식 ITEM 7개와는
새 실험이며, 영상 수 1~6개를 독립 묶음으로 평가합니다. 총 64장을 모델마다 동일하게 사용합니다.

SRC05 원본 918번 프레임(30.6초), SRC06 원본 954번 프레임(31.8초)은 픽셀 평균 0인
검은 화면입니다. 마지막 프레임을 균등 선택한 결과이며 decoder가 임의로 만든 누락 화면이 아닙니다.
원본 영상 자체에 대한 추가 검수는 필요합니다. 유리한 프레임으로 교체하지 않았습니다.
`inspection/contact.png`는 각 영상 시작/중간/끝 18이미지 확인용이고, 전체 768이미지의 사람 검수는 아닙니다.

정답 부족은 평가 불가이며 모델 오답으로 집계하지 않습니다. 유효한 입력에 대한 API의 잘못된
사건·근거·형식과 입력/변환/평가 오류는 분리합니다. 변환기인지 모델인지 확인하지 못한 원인은
`evaluation_unavailable`로 보존합니다.

초기에는 기존 승인 $5 원장의 예약 잔액 $0.00841472 때문에 새 유료 요청이 막혔습니다.
사용자가 2026-10-08 두 API의 이번 실행에 대해 비용 제한을 해제하여 추가 승인 파일을 기록했습니다.
12문제 전체 API 예약 상한은 $1.08251136입니다. 실제 청구액은 API 사용량/영수증 전에는 알 수 없습니다.
실제 호출은 어댑터 테스트·최종 검토 이후 진행하며, 결제 영수증 비용과 의미 정확도를
검증 없이 성공했다고 주장하지 않습니다.

팀에서 추가로 필요한 작업:

- canonical frame_number의 객체 클래스·박스 검수. 완전한 프레임과 부분 주석 프레임 구분.
- 영상별 사건 라벨과 불확실 판정 검수. 정상 영상/정답도 추가해야 오경보율 측정 가능.
- VLM 호출이 필요한 운영 조건을 합의하고 Clef 영상별 정답 및 rationale 작성.
- 구역·권한·시간 정책 확정. 경계 통과와 법적 무단 침입을 혼동하지 않기.
- 예산 소유자와 API 무료/유료 한도 확인. 추가 과금은 명시적으로 승인된 원장으로 관리.
